# 📊 Data Analytics Project

## 📌 Overview
This project focuses on performing end-to-end data analytics using Python, SQL, and Power BI. The workflow includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, dashboard creation, and reporting. The project demonstrates practical skills in data processing, visualization, and business insights generation.

---

## 📂 Dataset
- Dataset Name:Customer Behaviour Analysis
- Format: CSV 
- Description:
  The dataset contains information related to customers behavoiur and is used to analyze trends, patterns, and key insights.

## 🔄 Project Workflow

### 1. Data Loading
- Imported dataset using Python.
- Loaded CSV/Excel data into Pandas DataFrames.

### 2. Exploratory Data Analysis (EDA)
- Checked dataset structure and summary statistics.
- Identified missing values and duplicates.
- Performed trend and distribution analysis.
- Created visualizations for better understanding.

### 3. Data Cleaning
- Removed duplicate records.
- Handled missing/null values.
- Converted data types where required.
- Standardized column names and formats.

### 4. SQL Analysis
- Imported cleaned data into databases.
- Executed SQL queries using:
  - PostgreSQL
  - MySQL
  - SQL Server
- Performed:
  - Aggregations
  - Joins
  - Filtering
  - Ranking
  - Business KPI analysis

### 5. Dashboard Development
- Built an interactive Power BI dashboard.
- Added charts, KPIs, slicers, and filters.
- Created business insights visualizations.

### 6. Reporting & Presentation
- Generated analytical report.
- Created professional presentation slides using Gamma.
